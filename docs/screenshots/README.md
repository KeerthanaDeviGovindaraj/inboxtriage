## Replacing with live captures

If you'd rather use real browser captures than the generated ones, just overwrite these files (keep the same names) and the README will pick them up:

1. Run the app: `npm run dev`, open http://localhost:3000
2. On macOS press **Cmd + Shift + 4** and drag to select the area.
3. Save over the matching file here, then commit.
