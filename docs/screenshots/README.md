# Screenshots

Drop your screenshots here using these exact filenames so the main README renders them automatically:

| Filename | What to capture |
|---|---|
| `overview.png` | The full app on load — header with stats, model selector, sample sidebar, and the email input. |
| `result.png` | A triaged result card — ideally the **Priya** sample (IRS notice, high urgency), which shows category + urgency badges, extracted entities, flags, and the draft reply. |
| `demo-banner.png` | The yellow "demo mode" banner at the top after running a triage without an API key. |

## How to capture

1. Run the app: `npm run dev`, open http://localhost:3000
2. On macOS, press **Cmd + Shift + 4**, then drag to select the area (or press Space to capture a whole window).
3. Rename the saved file to match the table above and move it into this folder.

Tip: capture at a normal browser width (around 1000–1200px) so the layout looks balanced and the text stays readable in the README.

You can add more images — just reference them from `README.md` with:

```markdown
![caption](docs/screenshots/your-file.png)
```
